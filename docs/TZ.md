# Техническое задание: Android-приложение "Пропорции" (рабочее название)

## 1. Суть проекта

Минималистичный калькулятор пропорций ингредиентов. Пользователь сохраняет рецепт как набор пар "ингредиент — количество", затем при готовке меняет **любое** поле на реальное имеющееся количество — остальные пересчитываются автоматически по сохранённым исходным пропорциям.

**Отличие от конкурентов (Recipe Scaler, MealMaster, Recipe Calculator):** никакой рецептной книги — ни фото, ни шагов готовки, ни тегов, ни калорий, ни рекламы, ни аккаунта. Один инструмент, одна задача.

---

## 2. Целевая аудитория

- Домашние кулинары/кондитеры, готовящие по пропорциональным рецептурам (сиропы, тесто, маринады)
- Пользователи, которым не подходят рецептные комбайны из-за перегруженности интерфейса

---

## 3. Функциональные требования

### 3.1 Экраны (3, минимум 4-й опционален)

| № | Экран | Назначение |
|---|---|---|
| 1 | Главный экран | Список сохранённых карточек (имя + миниатюра-фото, если есть) + FAB "Добавить" + пустое состояние с подсказкой при первом запуске |
| 2 | Карточка рецепта | Один экран на **и создание, и использование**: динамический список строк "ингредиент — количество" (добавление/удаление строк), поле имени, кнопка "Сохранить". При открытии уже сохранённой карточки — те же поля, редактируемые; изменение любого поля пересчитывает остальные в реальном времени от исходных сохранённых значений |
| 3 | About            |  About screen with reference to policy and contact with author |
| 4 (опц.) | Настройки | Только если понадобится: язык, тема (тёмная/светлая), экспорт/импорт базы. **Можно не делать в MVP** |

**Итого: 3 экрана для MVP**, 4 не обязателен на старте.

### 3.2 Логика пересчёта (ядро приложения)
- При создании карточки все введённые значения сохраняются как исходные (baseline) вместе друг с другом.
- При изменении любого поля на уже сохранённой карточке: `коэффициент = новое_значение / исходное_значение_этого_же_поля`, все остальные поля = `исходное_значение × коэффициент`.
- Округление: до сотых для граммов/мл (настраиваемо позже, не в MVP).
- Изменения в режиме пересчёта **не перезаписывают** сохранённый baseline автоматически — нужна явная кнопка "Пересохранить с новыми значениями", иначе следующий пересчёт снова пойдёт от старого baseline (это важно продумать в UX, иначе пользователь запутается, какие цифры "истинные").

### 3.3 Автодополнение ингредиентов
- Список всех когда-либо введённых названий ингредиентов, отсортированный по частоте использования.
- Хранится локально, растёт по мере использования.

### 3.4 Опционально (не в MVP, но дёшево добавить позже)
- Фото карточки (для узнавания вместо чтения имени) — из галереи или камеры, хранится локально.
- Свободное текстовое поле "заметки" — без структуры, без шагов/таймеров.

---

## 4. Нефункциональные требования

- Платформа: Android, **Kotlin + Jetpack Compose** (Kotlin — предпочтительнее Java для нового проекта, у Google приоритет именно на него, Compose даёт готовый динамический список без ручной работы с RecyclerView)
- Хранение — локально, **Room DB**, без обязательной регистрации, без интернета вообще
- Целевые устройства: Android 8.0+

---

## 5. Монетизация

- Фримиум: 3 бесплатные сохранённые карточки, дальше — **разовая покупка** снятия лимита (не подписка — категория не оправдывает ежемесячный биллинг при таком объёме функциональности)
- **Без рекламы** — это прямая точка позиционирования против конкурентов с раздражающими баннерами
- Ориентировочная цена разблокировки: $1.99-3.99 разово

---

## 6. Объём и сроки (реалистичная оценка)

| Этап | Срок |
|---|---|
| UI (2 экрана, Compose) | 1 день |
| Логика пересчёта + Room | 1 день |
| Автодополнение ингредиентов | 0.5 дня |
| Полировка, тестирование, публикация в Play Console | 0.5-1 день |
| **Итого MVP** | **~3 дня** |

Твоя оценка "1-2 дня" оптимистична процентов на 30-50%, но порядок величины верный — это точно не месяцы.

## 7. Честные ожидания

Учитывая паттерн, который мы видели весь день: **органика будет медленной**, конкуренты в нише малочисленны, но существуют десятилетие (с 2015 года) и ни один не набрал большой массы — значит и у тебя, скорее всего, будет не взрыв, а тихий, постепенный рост через ASO на низкочастотных запросах ("ratio calculator recipe", "ingredient proportion calculator"). Реалистичная цель — не $5000/мес, а тот самый диапазон **$100-500/мес** в рамках портфельной стратегии, о которой договаривались. Это первый кирпичик, не финальная ставка.
